Алгоритм:
Преобразование строки в список символов для возможности изменения
Рекурсивная функция backtrack(start) генерирует перестановки, начиная с позиции start
Базовый случай: когда start достигает конца строки, добавляем текущую перестановку в результат
Рекурсивный случай: для каждой позиции от start до конца строки:
Меняем местами символы на позициях start и i
Рекурсивно генерируем перестановки для оставшейся части
Возвращаем символы на места (backtrack)
Временная сложность
O(n × n!)
Количество перестановок: n! (факториал длины строки)
Время на создание каждой перестановки: O(n) (преобразование в строку)
Итого: O(n × n!)
Пространственная сложность: O(n) для рекурсивного стека вызовов

Алгоритм использует метод backtracking для генерации всех возможных перестановок, что является классическим подходом для решения этой задачи. Метод эффективно перебирает все варианты, избегая дубликатов за счет правильного управления состоянием через swap операции.

Вопрос 10
Ответь на вопрос 
Разница между обходом дерева в глубину (DFS) и в ширину (BFS)

Основное отличие

DFS (Depth-First Search) - идет вглубь дерева до конца по одной ветке, затем возвращается  
BFS (Breadth-First Search) - идет по уровням, обрабатывает все узлы на одном уровне перед переходом на следующий

## 📊 **Визуальное сравнение**

Для дерева:
```
        A
       / \
      B   C
     / \   \
    D   E   F
```

**DFS порядок:** A → B → D → E → C → F  
**BFS порядок:** A → B → C → D → E → F

#Реализация

DFS
```python
def dfs(root):
    if not root:
        return
    stack = [root]
    while stack:
        node = stack.pop()
        print(node.val)
        # Добавляем детей в обратном порядке для правильного обхода
        for child in reversed(node.children):
            stack.append(child)
```

BFS
```python
from collections import deque

def bfs(root):
    if not root:
        return
    queue = deque([root])
    while queue:
        node = queue.popleft()
        print(node.val)
        for child in node.children:
            queue.append(child)
```

Сравнительная таблица

| Критерий         | DFS | BFS |
|---------        -|-----|-----|
| Структура данных | Стек | Очередь |
| Порядок обхода   | Вглубь | По уровням |
| Память           | O(h) - высота дерева | O(w) - ширина дерева |
| Время            | O(n) - все узлы | O(n) - все узлы |
| Короткий путь    | Не гарантирует | Гарантирует (в невзвешенном графе) |

использование

DFS лучше для:
- Поиска существования пути - быстрее находит путь если он существует
- Проверки связности
- Топологической сортировки
- Поиска циклов
- Задач где нужно исследовать одну ветку полностью

BFS лучше для:
- *Поиска кратчайшего пути в невзвешенном графе
- Поиска ближайших соседей
- Обхода по уровням
- Когда дерево очень широкое но неглубокое


DFS - исследовать всех друзей одного человека глубоко

 ⚠️⚠️⚠️Особенности памяти

- DFS использует меньше памяти в высоких узких деревьях
- BFS использует меньше памяти в широких неглубоких деревьях
- DFS может переполнить стек при большой глубине (рекурсия)
- BFS может использовать много памяти при большой ширине

Вариации алгоритмов

DFS варианты:
- Pre-order (корень → левый → правый)
- In-order (левый → корень → правый) - для бинарных деревьев поиска
- Post-order (левый → правый → корень)

BFS варианты:
- Level-order - классический обход по уровням
- Bidirectional BFS - поиск с двух сторон

Выбор между DFS и BFS зависит от конкретной задачи и структуры данных. DFS эффективен для исследования веток, BFS - для поиска кратчайших путей и обхода по уровням.
